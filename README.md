# 🎮 LORENZO GAMES — Repositório Oficial de Jogos 3D

Portal de jogos 3D web feitos em **HTML5, CSS3, JavaScript e Three.js** especialmente para o **Lorenzo e seus amigos** jogarem de qualquer computador, direto no navegador!

## 🕹️ Jogos Disponíveis

- **🏠 Portal Oficial (`index.html`)** — Página dedicada ao Lorenzo com acesso rápido a todos os jogos, guia de controles e botão de compartilhamento.
- **🔥 LORENZO GAME 3 (`lorenzo-game-3.html`)** — Edição Mega Titã:
  - 5 Cidades 3D Voxel
  - **Mew → Mewtwo → Mega Mewtwo → ✨ Shiny Mega Mew**
  - **Miraidon**, **Lucario**, **Greninja**, **Snorlax**, **Aerodactyl**, **Charmander → Mega Charizard X**, **Ceruledge**, **Cinderace**, **Tinkaton** e mais
  - **Arena Titã 3 vs 1** fora do mapa a cada 3 capturas diferentes (23 Chefes Gigantes: Koraidon, Salamence, Kyogre e +20!)
  - **Poder de Destruição Total** (colete 3 Orbes pelo mapa e aperte `Q`!)
  - Equipe de até **30 Pokémons** com opção de descartar (`🗑️`)
- **🗺️ LORENZO GAME 2 (`lorenzo-game-2.html`)** — Cidades & Evoluções:
  - 5 Cidades 3D + 17 Pokémons famosos (Charmander → Charizard, Dratini → Dragonite, Torchic → Blaziken, Pikachu, Bulbasaur, Squirtle) com evolução instantânea em 1 botão.

## 🚀 Publicação na Vercel
Este projeto é 100% estático — basta fazer `vercel --prod` ou conectar este repositório na Vercel!
